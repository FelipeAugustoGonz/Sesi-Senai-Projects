# SESI–SENAI Projects

**Software Engineering · Artificial Intelligence · Robotics · Embedded Systems · Industrial Automation**

A collection of academic, research, and engineering projects developed during my education at **SESI-SP** and **SENAI-SP**, in collaboration with classmates, educators, and partner organizations.

I'm **Felipe Augusto Gonzales Gomes**, a Brazilian high school student at SESI-SP and a technical student in Systems Analysis and Development at SENAI-SP. I am interested in designing software that interacts with the physical world—from computer vision and robotics to backend systems and industrial monitoring.

> **Project ownership:** Some initiatives presented here are collaborative. Project descriptions refer to the team's work; my specific contributions should be described in the corresponding project documentation. Features under development are not presented as deployed products.

## Selected projects

### EcoFlutuador — Environmental Robotics

A collaborative project exploring how robotics and intelligent software can support the collection of floating waste from aquatic environments.

**Engineering topics:** Python, computer vision, Raspberry Pi, ESP32, sensor integration, software–hardware communication, and API development.

Development includes research, prototyping, subsystem testing, and successive software/hardware iterations. For architecture, setup, current implementation status, and limitations, consult the EcoFlutuador project documentation when available in this repository.

**Community and outreach:** The project has also been shared in educational activities and discussions about technology and sustainability. Related material includes the IV International Congress of Education, the UNESCO Pororoca initiative, and exchanges connected to SP Ocean Week; supporting media and details should be added to each project record before publication.

### Mentor Maker — AI for Investigative Learning

A collaborative educational robotics project designed to support learners in understanding problems without simply providing ready-made answers. The concept combines a humanoid robot with AI-supported guidance and embedded interactions.

**Engineering topics:** Pepper, Python, Flask, ESP32, AI integration, service communication, and human–robot interaction.

**Recognition:** The **FPSMAKER_023** team from SESI Votorantim received **2nd place at SESI Makerthon 2026**, according to the official SESI-SP report. The report identifies 121 submitted projects and six finalists.

### U.L.T.R.O.N — Industrial Monitoring

A multidisciplinary project developed in the context of a challenge with **SCOMPTEC** to explore non-invasive acquisition and visualization of CNC machine signals.

**Engineering topics:** industrial inputs, Arduino Opta, telemetry, backend APIs, relational databases, and monitoring dashboards.

The project should be understood as a prototype/pilot initiative; no deployment or predictive-maintenance performance is claimed here. Industrial documentation and photographs should be published only when authorized.

### SENAI Sorting System — Automation

A practical industrial automation exercise using **Arduino Opta**, sensors, a conveyor, and actuators to classify and route items. The work explores sequential logic, timing, detection, actuation, and telemetry.
